# Deploying to Vercel (frontend) + Render (backend)

The project is split into two independently deployable apps:

| Folder | Platform | Framework | Public URL |
|---|---|---|---|
| `frontend/` | **Vercel** | React + Vite | `https://<project>.vercel.app` |
| `backend/` | **Render** | NestJS + MongoDB | `https://<service>.onrender.com` |

Both deploy from the same GitHub repo, each using its own subfolder as the root
directory.

---

## How the two talk to each other

The frontend's `vercel.json` rewrites every `/api/*` request to the Render backend:

```
Browser  ->  https://<project>.vercel.app/api/students
              ↓ Vercel server-side rewrite
         ->  https://<service>.onrender.com/api/students
```

Because the browser only ever sees the Vercel origin, **there is no CORS preflight and no
second public hostname to share**. The client is deployed once and the API URL never has to
be baked into the JavaScript bundle.

## Deploy the backend to Render first

Render must exist first, because the frontend rewrite points at it.

### Option A — Blueprint (recommended)

1. Render Dashboard → **New** → **Blueprint**
2. Connect `AkshayShingade19/Sai-Prasad-Driving-School`
3. Render reads `backend/render.yaml` automatically:
   - Root Directory: `backend`
   - Build: `npm ci --include=dev && npm run build`
   - Start: `npm run start:prod`
   - Health check: `/api/health`
4. Set the environment variables it asks for:

| Key | Value |
|---|---|
| `MONGODB_URI` | `mongodb+srv://akshay:<db_password>@cluster0.i2vslhw.mongodb.net/sai_prasad_driving_school?retryWrites=true&w=majority` |
| `JWT_SECRET` | a long random string — `openssl rand -hex 32` |
| `CLIENT_URL` | your Vercel URL, e.g. `https://<project>.vercel.app` |

> The blueprint already sets `NODE_ENV=production`, `JWT_EXPIRES_IN=7d`,
> `BUSINESS_TIMEZONE=Asia/Kolkata`, `RATE_LIMIT_MAX=200` and `BIND_ADDRESS=0.0.0.0`.
> `JWT_SECRET` is auto-generated by Render.

5. Deploy. The URL will be `https://sai-prasad-driving-school-api.onrender.com`.

### Option B — One command from your machine

```powershell
$env:RENDER_API_KEY = "rnd_xxxxxxxx"     # Render Dashboard -> Account Settings -> API Keys
$env:MONGODB_URI    = "mongodb+srv://..."
$env:JWT_SECRET     = "<random 64 chars>"
$env:CLIENT_URL     = "https://<project>.vercel.app"

powershell -ExecutionPolicy Bypass -File .\tools\deploy.ps1
```

`tools/deploy.ps1` creates the Render service, sets the environment variables, deploys
Vercel, patches the `/api` rewrite to the real Render URL, and prints the final URL.

## Deploy the frontend to Vercel

### Option A — Dashboard

1. Vercel Dashboard → **Add New** → **Project** → import the GitHub repo
2. Set the **Root Directory** to `frontend`
3. Framework preset: **Vite**
4. Deploy — `frontend/vercel.json` supplies the build command, output directory,
   SPA rewrites and cache headers

### Option B — CLI

```powershell
npm install -g vercel
$env:VERCEL_TOKEN = "<token from vercel.com/account/tokens>"
cd frontend
vercel --prod --token $env:VERCEL_TOKEN
```

## After the first backend deploy

Open the Render service's **Shell** tab and create the admin account:

```bash
npm run create-admin:prod -- --email owner@yourdomain.com --password "YourStrongPassword123"
```

Optionally seed demo data:

```bash
npm run seed:prod
```

## Environment variable summary

### Render (backend)

```
NODE_ENV=production
NODE_VERSION=22.11.0
PORT=3000                       # injected by Render
BIND_ADDRESS=0.0.0.0
MONGODB_URI=mongodb+srv://...
JWT_SECRET=<random>
JWT_EXPIRES_IN=7d
CLIENT_URL=https://<project>.vercel.app
BUSINESS_TIMEZONE=Asia/Kolkata
RATE_LIMIT_MAX=200
```

### Vercel (frontend)

No environment variables are required — the `/api` rewrite handles the backend URL.
To call a different API directly instead, set `VITE_API_URL` and remove the rewrite.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| Frontend loads, API 404s | The rewrite still points at the old backend | Re-run `tools/deploy.ps1`, or edit the `destination` in `frontend/vercel.json` |
| `MongooseServerSelectionError` | Wrong SRV string, or Atlas IP not open | Add `0.0.0.0/0` in Atlas Network Access |
| `Cannot find module '@nestjs/cli'` | `NODE_ENV=production` skipped devDependencies | Build command must be `npm ci --include=dev && npm run build` |
| Backend sleeps / first request slow | Render free tier idles after 15 min | Expected on the free plan; use the `starter` plan for production |
| `/admin/login` returns 404 on Vercel | SPA rewrite missing | `frontend/vercel.json` must contain the `/(.*)` → `/index.html` rewrite |
